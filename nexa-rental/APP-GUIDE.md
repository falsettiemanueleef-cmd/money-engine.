# NEXA Rental Profit Manager — alpha

App web installabile con dati salvati localmente. Moduli: immobili/unità, prenotazioni, spese, dashboard, import CSV generico con mappatura, export CSV e backup JSON, interfaccia in cinque lingue.

## Limiti da verificare prima della vendita
- Importazione CSV generica: non certificata per ogni schema Airbnb/Booking.com/Vrbo.
- Nessuna sincronizzazione API, login, cloud sync o conversione valuta.
- Occupazione stimata su 365 giorni per unità: non considera blocchi e periodi di disponibilità personalizzati.
- Ripartizione spese condivise, report avanzati e test reali su iOS non implementati/verificati.
- Non è software fiscale né consulenza fiscale.

Aprire su hosting HTTPS statico per PWA/service worker. Android: Chrome > Aggiungi a schermata Home. iOS: Safari > Condividi > Aggiungi a Home, se supportato.
